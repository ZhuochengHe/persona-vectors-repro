# Persona Vectors 被引文献筛选规则

更新日期：2026-10-30

本文是后续收集、筛选与聚类的基准文档。用户的新要求应先更新本文，再同步工作表；工作表中的探索性判断不自动成为规则。

## 目标与范围

目标是广泛阅读相关研究以确定研究问题，不局限于当前复现实验、已有假设或现有代码能够实现的问题。

唯一种子论文：**Persona Vectors: Monitoring and Controlling Character Traits in Language Models**（2025），arXiv:2507.21509，https://arxiv.org/abs/2507.21509 。

**只收集直接引用该种子论文的论文。** 不加入主题搜索找到但没有确认引用关系的论文，不扩展到种子论文的参考文献，也不递归收集被引论文的被引。

- 从种子论文的被引列表建立候选集，记录数据库、获取日期和被引关系来源。
- 被引总数随数据库、日期及版本合并规则变化；目前“三百多篇”是用户提供的规模，尚未核实，不能写成已抓取数量。
- 合并同一论文的 arXiv、会议和期刊等版本，保留原始记录及标识，避免重复计数。
- 若数据库记录存在疑问，检查正文参考文献；引用关系未确认的记录标记待核实，不计入已确认的被引集合。
- 不为补齐主题而添加被引集合之外的相关论文。Assistant Axis 等示例也必须遵守此范围限制。

## 保留的硬规则

**标题或摘要出现 persona，肯定保留，不得因与当前实验不够相关而排除。**

- 匹配不区分大小写，覆盖 persona、personas 以及 persona-based 等包含该词的表达。
- 单独出现 personality 不等同于命中此硬规则，但可以按主题相关性保留。
- 硬规则决定保留，不预先决定三档归类或阅读优先级。
- 缺失摘要不能当作“摘要未出现 persona”；应记录缺失并尽量补齐。标题已命中时直接保留。
- 本规则在种子论文的直接被引范围内生效，不绕过引用关系要求。

## 三档筛选

| 档位 | 标准 | 示例主题 |
|---|---|---|
| 核心相关 | 直接研究模型的人格、角色、情绪及其内部表征，或利用这些表征监测、干预行为 | persona vectors、人格空间、Assistant 身份、emotion directions、人格组合控制 |
| 问题相关 | 研究人格、情绪、角色或身份相关行为与动态，方法不限于向量 | 多轮人格漂移、人格一致性、情绪与行为变化、人格训练与形成 |
| 方法参考 | 人格或情绪不是主要对象，但提供相关的表征分析、控制、监测或评估方法 | steering 方法、因果验证、泛化、副作用、评估有效性 |

保留集包含以上三档，以及硬规则命中但暂时无法归类的论文。不得为了凑入三档而强行分类，允许标记“待归类”。

情绪相关工作可以纳入，区分：模型内部情绪概念／功能性情绪、模型表达的情绪／共情／语气、用户情绪对模型人格与行为的影响。纯情感分类等工作通常优先级较低，但若命中 persona 硬规则仍须保留。

通常排除仅顺带引用种子论文且主题和方法均不相关的工作；没有命中硬规则的普通用户画像、推荐系统、纯情感分类或无相关联系的通用应用可排除。不能仅凭关键词缺失排除，也不能用“对当前实验没用”作为排除理由。

## 判断流程与证据

1. 确认来自种子论文的直接被引列表，记录来源并去重。
2. 读取标题和摘要，记录 persona 命中位置；命中即保留。
3. 对其他记录按主题和方法判断三档；信息不足标记待定。
4. 边界案例补读方法、实验及引用种子论文的具体段落，记录判断依据。
5. 区分标题／摘要判断与全文判断，不把摘要阅读写成全文审阅。

筛选状态、三档相关性、阅读优先级是三个独立字段。排除项与待定项保留理由；不预设最后应剩多少篇，不按引用量直接决定阅读优先级。

## 第二轮：高价值精选（2026-10-30新增）

用户要求进一步压缩阅读量，优先考虑优秀高校／研究机构、公司研究论文、顶会，以及idea突出的工作。新增独立精选集；第一轮的相关性保留不再等同于值得优先精读。

- 候选仍只来自已冻结的种子论文直接被引集合，不用主题搜索添加新候选。
- persona硬规则继续保证论文留在总清单，但不保证进入第二轮精选。
- 优先选能提出新问题、新机制或新结论，或者提供可靠反例／负结果的论文。仅把原方法换模型、换应用、增加工程模块，且没有独立洞见的工作降低优先级。
- 对同主题重叠论文选代表，尽量减少重复阅读；不把每个主题都凑成同样数量。
- 学校、机构、公司和会议是优先级信号，不代替对贡献和证据的判断；idea突出者可在缺乏这些信号时入选。
- 核对论文署名机构，不能由作者履历猜本篇单位。区分公司署名论文、公司资助和作者曾在公司工作。
- 区分主会、Findings、workshop、在审、预印本；优先用官方会议录／接收页面核实。仅arXiv作者自报时明确标记，未核实时不写成已确认顶会。
- 对精选论文记录具体贡献、值得读的原因、证据范围、重要限制和机构／会议来源。缺少证据时标未知，不编造。
- 未入精选表示当前阅读预算下延后，不代表已经证明论文没有贡献。

已生成[精选阅读导航](citation_screening_shortlist.md)和[精选CSV](citation_screening_shortlist.csv)：30篇，其中A档10篇、B档20篇。对43篇候选核查了署名及正文贡献／讨论／局限片段，11篇精选的主会已用官方会议录确认。第一轮351篇相关记录中的321篇移出当前主阅读清单，保留延后状态；总表记录第二轮去向和理由。其余308篇没有进一步作贡献高低定论，不能说这些论文均无贡献。

## 后续聚类

筛选后按研究问题和实际文献分布聚类，不按当前实验工作包组织。每篇允许一个主类和多个交叉标签；聚类可以随阅读调整。

下列仅为初始候选主题，不是固定分类框架：

- 人格空间与几何结构
- 人格形成、预训练与后训练变化
- 情绪表征及其与人格的关系
- 多轮动态、身份与人格稳定性
- 控制方法、组合与干预副作用
- 人格与实际行动、策略及社会行为
- 监测、评估与表征有效性

Assistant Axis 是用户明确感兴趣的主题锚点；不能据此把所有文献限制为该路线。每个最终类应提供阅读顺序、代表论文、主要问题、不同结论及开放问题，帮助用户逐块阅读并形成自己的问题。

## 工作文件

独立工作表：[citation_screening_working.csv](citation_screening_working.csv)。它用于记录原始候选、筛选、证据和暂定聚类，可持续更新；本规则文档保持为判断基准。

当前状态（2026-10-30）：已抓取mlsanity直接被引接口的完整376条快照，并从官方arXiv补齐376条标题和摘要。已完成逐篇标题/摘要初筛，暂保留351条（核心166、问题相关92、方法参考93）、待定13条、排除12条；85条persona硬规则命中项全部保留。已做九个方向的初步人工聚类及起步阅读导航，见[阅读总导航](citation_screening_reading_map.md)。这不是376篇全文审阅，也不是跨数据库完整性结论。

来源状态区分：`source_listed_direct_citer`表示冻结被引列表报告的引用关系；`verified_in_primary_html`表示额外在官方正文HTML定位到了种子引用。不能把二者都描述为已经独立核实参考文献。对27条做正文引用抽查，24条找到引用；其余3条仍保留源列表口径。C148/C173疑似前作/扩展版，尚未确认版本同一性，因此376条不同arXiv ID不等于376项独立研究。

工作CSV是人工决策的可读工作视图；当前逐篇判断和分组阅读串分别保存在`citation_screening_sources/review_decisions.json`与`reading_group_specs.json`。直接修改CSV后，应将判断同步到决策源文件，再运行渲染脚本，避免重建时丢失修改。`method`、`research_question`等详细笔记字段留给后续阅读，未从标题猜填。
