# 文献笔记：粒度与思考方向

这份约定用于本仓库的论文阅读表和文献分析。依据是用户对 Assistant Axis（ID 3）的手写笔记，以及对 ID 1、2 细化笔记的要求。它保存的是阅读需求，不是 write-like-me 插件技能的副本，也不依赖插件可用。

## 目标

对齐细节粒度与研究思路，不要求模仿用户的语气、用词、中英混用或句式。使用清楚、准确的中文，保留必要的英文术语与公式。读者应能据此解释方法、判断证据边界，并提出下一步可验证的问题，而不只记住摘要结论。

深度取决于实际阅读范围。仅读摘要时不能写成方法已经核实；需要细化的论文优先查正文与相关附录。不同论文不必凑相同字数、条数或同一套研究问题。

## Contributions：解释怎么做，以及新在哪里

- 先交代研究问题和相对已有工作的增量，避免“提出一个有效框架”等空泛总结。
- 写清关键方法链：输入／数据如何构造、对比对象、提取位置与聚合方式、如何选择方向或主成分、怎样测量和干预。重要的公式应解释各项及方向；例如训练时正向注入坏trait与推理时反向抑制的目的不同。
- 在影响理解或复现时交代模型、训练阶段、层、阈值、样本划分及评估器；不堆无关超参数。
- 区分测量相关性、干预证据和机制解释。写明实验实际支持了什么，哪些只是作者的解释。
- 保留反直觉结果与分离现象，例如语言风格和实际决策、self-behavior和对他人的预期、默认Assistant身份和具体trait。
- 附上能定位的章节／附录或来源；公开代码与论文不一致时分开记录。

## Limitation：指出结论在哪里不成立或还不知道

- 区分“作者明确的局限”“实验显示的边界”和“阅读者提出的待验证问题”。推测不能写成已证实缺陷。
- 具体说明适用范围：模型与规模、dense／MoE、chat／reasoning、激活访问条件、任务与对话长度等；只写与该论文有关的范围。
- 检查表征假设：单轴是否足够、可能的非线性或多成分、trait与角色／语气的纠缠、相关方向是否真能独立控制。
- 检查评估是否测到了目标：judge与数据构造的共享偏差、评分与行动是否一致、单轮题能否代表真实多轮行为。
- 检查稳定性及成本：选层／扫系数、采样和题目变化、跨模型迁移、强干预退化、计算开销、训练后是否换方向绕过监测。
- 说明局限影响哪项结论、需要什么证据才能补足，避免只列“泛化有限／模型较少”。已有相关控制也应承认。

## Future work：从缺口走向可区分的实验

独立填写 `Future work`，明确标注“作者提出”与“阅读推演”。优先从当前结果或局限出发，写出问题、可能解释，以及能区分解释的比较／测量；不要只写“扩大规模、探索更多模型”。

本项目可关注的方向包括：

- 人格空间的维数、自然基底、主轴外的成分，以及单轴与子空间／非线性方法的差别。
- 预训练与后训练分别形成了什么；训练前后默认Assistant方向、具体trait和行为如何共同变化。
- 角色扮演、身份、trait、语言风格、信念与实际决策能否分离。
- 能否在漂移或危险行为发生前预测，而非只在答案生成后检测。
- 训练期干预能否减少漂移，同时保留任务学习；重新提取方向后是否仍成立。
- 跨题目、采样、模型、多轮及真实互动的验证，如何控制混杂与评估失真。

这些是选题视角，不是每篇论文必须套用的清单。与已有论文建立联系时使用稳定paper ID，并说明联系是方法借鉴、证据补充还是待检验猜想。

## 用户原文与同步

`Additional think` 专属用户。agent不得生成、改写、纠错或自动搬走其中的内容；用户笔记可作为理解关注点的参照，不自动视为已核实的论文事实。即便笔记里已经写了方法、贡献或future work，也保留原文，在其他列独立整理有来源的分析。

保留用户在其他列的修改与阅读状态。Windows表和仓库CSV的同步、备份、冲突及Slurm例外遵循 [AGENTS.md](../../AGENTS.md) 和 [交接流程](handover_paper_excel.md)。

## 论文分类与Research question

`Paper type`按主要贡献多选，区别于研究主题：Method提出方法；Benchmark提出评估任务／数据／协议；Survey系统整理已有工作；Analysis实证分析规律；Theory包含正式数学命题与证明。使用公式、向量或几何分析本身不足以归Theory；没有合适论文时不强行填满类别。当前分类依据已有笔记，未精读条目仍是工作标签。

`Research question`用一至数个问句明确论文要解决的问题，与一句话主题／结论区分。Google Doc按研究问题组织论文，每篇保留稳定ID、分类、RQ、方法贡献、局限、Future work、用户笔记及证据范围；左侧大纲承担导航，长内容使用段落，不塞入宽表格。
