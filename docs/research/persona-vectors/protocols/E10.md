# E10: Reverse steering on E08 fine-tuned models

## Question and contrast

Can a frozen persona vector reduce behavior acquired by ordinary SFT at inference time, and what coherence or capability cost does that introduce? This follows paper §5.1. Begin from the 15 E08 adapters and the same Qwen3.5 base checkpoint. This is an inference-only intervention; it does not retrain adapters or combine E10 steering with E11 training-time steering.

## Freeze eligible models and settings

1. On the 10 development questions for each trait, compare every E08 adapter to the base and identify cells with a reproducible increase in any of the three trait scores. Freeze the list of eligible `(category, version, trait)` cells and the selected E02 layer for each trait before opening final test results. Include all cells in the summary, marking non-eligible cells explicitly.
2. Load the corresponding frozen E01 raw mean-difference vector for each trait. Use the per-trait E02 selected layer and scan coefficient `0` plus `{-0.5, -1.0, -2.0}`. Negative coefficients subtract the vector from the residual stream; zero uses the same generation path and hooks.
3. Use the non-thinking, text-only shared runtime and fixed generation settings. Generate 10 paired rollouts for each of the 10 held-out questions per trait, using the same derived seeds at all coefficients.

## Evaluation and selection

Score evil, sycophancy, and hallucination with `gpt-5.6-luna`, using the upstream trait rubrics and coherence rubric without calibration. Evaluate the same stratified 1,000-question MMLU subset for the unsteered E08 adapter and every steering coefficient. Keep raw completions, token IDs, finish reasons, judge records, and MMLU choice probabilities.

For each eligible cell and affected trait, report the paired trait change from coefficient zero, coherence change, and MMLU change at every coefficient. Select the coefficient on development data that maximizes trait-score reduction subject to coherence being no more than 5 points below the unsteered E08 adapter. If none qualifies, report no acceptable operating point. Break ties by smaller absolute coefficient. Report held-out results only for the frozen choice, while retaining the complete coefficient sweep as a secondary curve. Do not interpret the small fixed question set as independent rollout observations; cluster uncertainty by question.

E10's primary comparison is unsteered E08 adapter versus the same adapter with negative steering. The base model is a context reference, not a replacement baseline. Report the full E08 matrix so that checkpoint selection cannot hide unaffected or increased-trait cells.

## Runtime invocation

Use shared `generate --adapter ADAPTER --vector VECTOR --layer L --coefficient NEGATIVE`, `score`, and `mmlu` with the same intervention. See [RUNBOOK](../../runbook.md).
